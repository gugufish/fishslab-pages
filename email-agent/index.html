email-agent

email-agent 是 Gilbert (aka Fish) 個人自用的郵件代收程式，執行在本人自有的 NAS 上， 僅供本人的帳號使用，不對外提供服務。

功能：定期以 IMAP 登入本人的其他信箱，將新信件透過 Gmail API 匯入本人的 Gmail， 保留原始寄件者，並依本人在 Gmail 設定的篩選器貼上標籤。

email-agent is a personal, self-hosted mail collector used only by its author. It fetches new mail from the author's other mailboxes via IMAP and imports it into the author's own Gmail account through the Gmail API, then applies the author's existing Gmail filters.
