email-agent 隱私權政策

最後更新：2026-10-30

適用範圍

email-agent 是 Gilbert (aka Fish) 個人自用的郵件代收程式，只用於本人的 Google 帳號與本人的其他信箱，不提供他人使用。

存取的 Google 資料

經本人授權後，程式透過 Gmail API（gmail.modify 範圍）執行以下動作：

  • 將從本人其他信箱收到的信件匯入本人的 Gmail。
  • 以 Message-ID 搜尋剛匯入的信件，判斷符合哪些篩選器。
  • 讀取本人在 Gmail 設定的篩選器，並依其動作新增或移除信件標籤。
  • 建立代收用的標籤。

程式不會讀取、分析或匯出 Gmail 中其他既有信件的內容。

資料保存

OAuth token 與外部信箱密碼以 AES-256-GCM 加密後，保存在本人自有 NAS 上的資料庫；處理紀錄只保存寄件者、主旨等摘要資訊。 資料不會上傳到任何第三方服務，不會出售、分享，也不會用於廣告。

Google API 使用聲明

email-agent 對 Google API 所取得資訊的使用與傳輸，遵守 Google API Services User Data Policy， 包含其中的 Limited Use 規定。

撤銷授權與刪除資料

可隨時在 Google 帳戶的第三方存取權 撤銷授權； 刪除 NAS 上的程式資料目錄即會移除所有保存的資料。

Summary (English): email-agent is a personal, self-hosted tool used only by its author. With the author's consent it uses the Gmail API (gmail.modify) to import mail from the author's other mailboxes, search the imported messages, read the author's Gmail filters and apply their label actions, and create labels. Tokens and passwords are stored encrypted on the author's own NAS and are never shared with third parties. email-agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
